PCF Design Notes (for stakeholder reference)

  • PCF type: Field control (FetchXmlFilterTable) placed on a Model-Driven App custom page via a dummy host field
  • Data source: Live Dataverse queries via context.webAPI — results are always real-time
  • Cascading dropdowns: Selecting a Domain triggers a WebAPI call to reload only that slot's Expertise dropdown
  • Filter logic: AND across all active criteria — an expert must match Language AND Expertise slot 1 AND Expertise slot 2
  • Regions: Searched the same way as any other expertise — select "Regions" as the Domain, then pick a region in the Expertise dropdown
  • Click-through: Expert names link directly to their ExpertProfile record in the MDA
  • Reusability: The same PCF control can be placed on any form with different FetchXml configuration — no code changes required
